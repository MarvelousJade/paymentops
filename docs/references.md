## Capability comparison

Stripe offers real payment-method integration, authorization expiry and merchant tooling; PaymentOps only demonstrates a small synthetic workflow. This is neither feature parity nor comparable maturity. PaymentOps exposes the application/database evidence for study, whereas Stripe documentation describes a public contract, not its internals.

The outbox pattern provides reliability reasoning, not a working end-user product or an automatic exactly-once guarantee. PaymentOps must verify atomic claims/effects and handle relay redelivery itself. Testcontainers provides repeatable infrastructure, not business correctness: HTTP, invariant and regression assertions remain necessary. Local transport is easier to run and debug but cannot establish Kafka delivery/rebalance behavior.
